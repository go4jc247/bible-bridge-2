Shrink Bible audio

Makes a whole Bible's audio files much smaller so they fit comfortably on your phone. A single voice still sounds clear. File names stay the same, so Bible Bridge still knows which chapter each file is.

Working…

Keep this page open with the screen on and the phone plugged in. If it stops, open this page again, choose the same files, and it carries on from the next zip.

Everything happens on this phone. Nothing is uploaded. MP3 encoding by LAME (lamejs, LGPL).
